# Examples

These are authored prompt proposals, not generated-image results. JSON files are internal review records, not NovelAI import files.

`portrait.json` is a sparse dark oil-paint proposal with an explicitly described iris gradient. It uses a generic appearance description rather than claiming a verified character tag.

`portrait-refined.json` changes only Base lighting/background wording. Its locked fields are identical to the original. This proves string preservation, not visual identity preservation.

`two-characters.json` assigns colors and props to separate character boxes. Cross-character UC is scoped: blue hair is excluded only for the left character, not globally.

`title-poster.json` requests visible text and space. Both automatic quality additions and UC presets are off, so their unknown V5 expansions are not silently assumed.

All generation parameters are null because these drafts have not been run in NovelAI. Treat parameter proposals separately from observed settings.
