# Diagnosis as controlled revision

Start with the actual image, the exact prompt fields and available settings. An image alone supports visual observations, not recovered model settings. A prompt alone supports hypotheses, not claims about its unseen output.

| Symptom | Check first | One bounded revision | Observe next |
|---|---|---|---|
| Iris colors wrong | Gradient within each iris versus left/right heterochromia | Replace ambiguous eye wording with one precise sentence | Internal gradient and consistency between eyes |
| Plastic-looking skin | Glossy/rendering terms and intended material | Change only surface/highlight wording | Texture, highlight width, identity drift |
| Background too busy | Extra props, competing lights and preset suppression of space | Remove nonessential props; review negative-space suppression | Subject separation and empty-area proportion |
| Characters share attributes | Base contains per-person features | Move attributes into individual character fields | Hair, clothes and actions assigned to each subject |
| Title missing | Text request, model support, `no text` and preset risks | Resolve conflict; keep Text segment at the end | Spelling and layout; consider post-typesetting |
| Composition drifts | Unrelated framing tags or multiple variables changed | Restore framing string and alter one remaining variable | Crop, pose and hierarchy |

Do not stack heavy negative weights as a universal remedy. Keep a previous version. Treat seed reuse as an experimental control, not an identity lock. One successful output remains one observation, not a proven optimum.

If an enabled preset conflicts with the goal, provide a proposed setting change and a replacement custom UC. Do not claim that a supplement cancels hidden terms. Any actual UI/API change is a separate authorized action.
