# Standalone skill

This folder contains the installable NovelAI Prompt Studio skill. Place the complete folder at a local skill discovery location supported by your host; do not install just SKILL.md, because its references and scripts are needed.

Open `SKILL.md` for the workflow and `references/SOURCES.md` for dated sources and known gaps. The scripts are offline Python 3.10+ tools with no runtime dependencies. Example JSON files are review records, not NovelAI import payloads. No image-generation tests or host activation are implied by installing these files.

For source tests, release builds and guarded GitHub publication, use the separate source package. Original project files are MIT-licensed; no proprietary images or tutorials are included.
