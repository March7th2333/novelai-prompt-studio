# NovelAI Prompt Studio v1.0.0

An instruction-first NovelAI prompting skill with five modes, constraint-preserving revisions, scoped character prompts, version-aware checks and explicit evidence gaps.

Includes a dependency-free Python linter and diff tool, optional creative presets, review-record examples, local installation, allowlisted archives, and a guarded GitHub publishing helper.

Known limits: no paid generation calls, no actual image-generation evaluation, no exact tokenizer, no complete V5 preset snapshot, and no promise of deterministic visual identity. See README and the evidence ledger for details.
